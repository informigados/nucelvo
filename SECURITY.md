# 🔒 Security policy

## Supported versions

Please report issues affecting the latest published preview or the default branch.

## Reporting a vulnerability

Use [Report a vulnerability](https://github.com/informigados/nucelvo/security/advisories/new) to share the report privately. If the form is unavailable, open a [GitHub issue](https://github.com/informigados/nucelvo/issues/new) asking for a private reporting channel. Keep the issue free of vulnerability details.

Include the affected version or commit, the operating system, the impact, and the conditions needed to reproduce the issue. Remove identifying information from any attachments.
