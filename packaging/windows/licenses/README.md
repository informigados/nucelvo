# Additional upstream license files

The Windows packager includes these upstream files for crates whose published
Cargo packages omit their repository-level license text. Package versions are
listed in [packages.json](packages.json).

- [AccessKit](https://github.com/AccessKit/accesskit/tree/f3026222559c7f5f46d8f25cb7404de68eb149f0)
- [clipboard-win](https://github.com/DoumanAsh/clipboard-win/tree/ed27008ae5d1f10cfbb266de039f0fb35fd05a56)
- Lyon license files are identical at the revisions used for [lyon_algorithms and lyon_geom](https://github.com/nical/lyon/tree/db98d26a1a90076a7a894262dcb51117eef643c8) and [lyon_extra and lyon_path](https://github.com/nical/lyon/tree/56219c95c658d4f39de7b190d98e57d5773ba241).
- [rspolib](https://github.com/mondeja/rspolib/tree/8170d99ebad29d894712ccb3dc6d0be2198d3055)
- [Taffy](https://github.com/DioxusLabs/taffy/tree/0064bd54cbe38bf1d8bcd6ec6ab0704d45fb048a)
