# Nucelvo brand

| Asset | Use |
| --- | --- |
| [Logo for light backgrounds](nucelvo-logo-light.svg) | On light surfaces, such as `#F7FAF8` |
| [Logo for dark backgrounds](nucelvo-logo-dark.svg) | On dark surfaces, such as `#14221F` |
| [Icon SVG](nucelvo-icon.svg) | Transparent, scalable app icon for both backgrounds |
| [Icon PNG](nucelvo-icon.png) | Transparent raster export at 256 × 256 |
| [Icon ICO](nucelvo-icon.ico) | Windows icon in 16, 24, 32, 48, 64, 128 and 256 px |
| [Made with Slint badge](made-with-slint.png) | Upstream attribution artwork for the public README |

The lettering is drawn as paths. Maintain the logo’s 288 × 64 proportions and the icon’s square proportions when resizing. The desktop header switches logo variants with the system theme.
